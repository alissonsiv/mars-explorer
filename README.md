
# Mars Explorer

Interactive 3D Mars exploration app built with Three.js. Explore real NASA mission data or walk in first-person through Perseverance's actual Jezero Crater waypoints in a guided story mode.

## How to Run

1. **Clone the repository:**

   ```bash
   git clone <repository-url>
   ```

2. **Navigate to the project folder:**

   ```bash
   cd mars-explorer
   ```

3. **Run with Live Server:**
   - Install the Live Server extension if you haven't already.
   - Open the `index.html` file.
   - Click **Open with Live Server**.

4. The application will automatically open in your browser.
