
# Mars Explorer

Aplicação interativa de exploração de Marte em 3D, desenvolvida com Three.js. Explore dados reais de missões da NASA ou caminhe em primeira pessoa pelos pontos de referência do rover Perseverance na cratera Jezero, em um modo de história guiado.

## Como executar

1. **Clone o repositório:**

   ```bash
   git clone <url-do-repositorio>
   ```

2. **Acesse a pasta do projeto:**

   ```bash
   cd mars-explorer
   ```

3. **Inicie o Live Server:**
   - Instale a extensão Live Server, caso ainda não tenha.
   - Abra o arquivo `index.html`.
   - Clique em **Open with Live Server**.

4. A aplicação será aberta automaticamente no navegador.
